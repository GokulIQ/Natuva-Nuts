Quick Start

Natuva Gourmet is 100% frontend static code. No Node.js build process, NPM install, or server-side compiler is required to view or customize the template.

  1. Unzip the package: Extract the template folder to your preferred workspace.
  2. Open in Browser: Double-click index.html or open via VS Code Live Server / Local Web Server.
  3. Theme Selection: Use the sun/moon icon in the navbar to test Dark and Light mode, or the globe icon to toggle LTR / RTL Arabic mode.
  4. Customize Content: Edit the HTML files in any code editor (VS Code, Sublime, WebStorm).
Tip for Best Performance: While double-clicking works for all HTML pages, running a local HTTP server (like VS Code Live Server or Python's python -m http.server) ensures smooth SVG font loading across all browser security policies.

Dark Mode & RTL Engine

Natuva Gourmet features an instantaneous, zero-flash theme and layout engine inside assets/js/theme.js.

  • Theme Persistence: Automatically checks localStorage.getItem('natuva_theme') or system preferences (prefers-color-scheme).
  • RTL Support: Full Arabic/Hebrew bidirectional layout support toggled via the globe icon, loading assets/css/rtl.css dynamically.
  • Zero Theme Flash: The script runs inline before DOM render to prevent any white screen flashes when opening dark pages.

Shopping Cart & LocalStorage

The cart in assets/js/cart.js provides a full slide-out offcanvas drawer with:

  • Reactive Quantities: Add, increment, decrement, and remove items with real-time subtotal calculations.
  • Free Shipping Bar: Interactive progress bar towards the ₹7,098.75 free shipping goal.
  • Promotional Coupons: Try entering GOURMET10 (10% off) or FREESHIP (free express shipping).
  • Checkout Simulation: Modal with realistic order review, address preview, and order confirmation.

Forms & Submissions

Forms on contact.html, bulk-orders.html, and the footer Newsletter are handled by assets/js/forms.js with:

  • Client-side HTML5 constraint validation.
  • Inline field feedback (highlighting invalid fields and focusing the first error).
  • Animated spinner buttons and simulated async responses for static demonstration.

For full instructions on connecting these forms to Web3Forms, Formspree, or PHP Mailer, see the included documentation/integration-guide.md file.
